# Watch online

You don't need to install anything to try SurfArr. [surfarr.tv](https://surfarr.tv) has a watch page that runs the same channels in your browser.

## The watch page

- Pick a channel from the guide and it starts mid-episode, wherever the virtual clock is, just like your own install.
- When an episode ends, the next one starts right away.
- YouTube and Internet Archive episodes play in the same player.

## Chat

The watch page has a live chat next to the TV. Pick a name and say hi. It's lightly moderated, so a few rules are enforced automatically:

- **No links**, and only letters, numbers and basic punctuation.
- **Bad words are filtered.**
- **Spam limits**: a short wait between messages, no repeating yourself, and a cap on bursts. Breaking these repeatedly mutes you for a while, and the mute gets longer each time.
- Recent messages stay up for a few days and don't disappear when the server restarts.

Chat is part of the hosted site only. A self-hosted SurfArr doesn't include it.
